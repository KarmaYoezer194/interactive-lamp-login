# Interactive Lamp Login / Signup

A dark login page with a desk lamp. Pull the lamp's string to switch it on: the room lights up teal, a light beam falls across the page, and the Sign In / Sign Up card fades in.

## Features
- Draggable pull-string with a springy bounce (pull again to turn the lamp off)
- Light beam, glowing shade and floating dust particles
- Sliding Sign In / Sign Up tabs
- Input focus glow, show/hide password, remember-me checkbox
- Loading spinner, then a "Signed In Successfully" screen with a "Test Again" button
- Responsive layout for phones

## Run it
Open `index.html` in a browser. No build step needed.

Built with plain HTML, CSS and JavaScript, using the Plus Jakarta Sans font.
